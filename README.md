# Overview

Service Window is a mobile application prototype designed to help independent food truck owner-operators manage inventory and monitor stock levels during daily operations.

# Technology Stack

- Framework: React Native
- Development Platform: Expo SDK 58
- Language: JavaScript
- Runtime: Node.js 24 LTS
- Package Manager: npm
- Version Control: Git and GitHub

# Features

Planned features include:
- Viewing current inventory items and stock quantities
- Increasing and decreasing inventory quantities
- Highlighting inventory items that fall below their minimum stock levels
- Supporting inventory-related management tasks through a mobile-friendly interface

# Prerequisites

- Node.js 24 LTS
- npm
- Git
- Expo Go or a compatible development build for mobile testing

# Installation

1. Clone the GitHub repository: `git clone https://github.com/Kodali7/Team3-HCI-DP4.git`
2. Navigate to mobile directory: `cd Team3-HCI-DP4/mobile`
3. Install dependencies: `npm ci`
4. Start the development server: `npx expo start`
5. Scan the QR code displayed in the terminal using Expo Go on your mobile device.

Your device's Expo Go version should be compatible with Expo SDK 58. Your computer and mobile device should be connected to the same Wi-Fi network for local development.

# Project Structure

mobile/App.js – Main React Native application component

mobile/index.js – Application entry point

mobile/assets/ – Application images and icons

mobile/app.json – Expo application configuration

mobile/package.json – Project dependencies and scripts

mobile/package-lock.json – Dependency lockfile for reproducible installations
